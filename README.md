# ❄ Desktop Snow — снег на рабочем столе Windows

Новогодний снегопад поверх рабочего стола, как зимняя тема в Telegram.
Снежинки падают поверх всех окон, клики проходят насквозь, а на иконках
и панели задач постепенно вырастают сугробы — точно по форме каждой иконки.

*A festive snowfall overlay for Windows 10/11: click-through, snow piles up on desktop icons and the taskbar, tray icon, Qt6 settings, hides itself in games.*

## Возможности

- **Снегопад в три слоя** — дальние мелкие снежинки, средние и крупные ближние, со сглаженными краями, ветром и покачиванием.
- **Сугробы по форме иконок** — программа берёт настоящую картинку каждой иконки рабочего стола и кладёт снег по её верхнему контуру: на крышку Корзины, вкладку папки, макушку круглого значка. С крутых склонов снег осыпается.
- **Сугроб на панели задач** — мягкие холмы вдоль верхнего края.
- **Клики проходят насквозь** — снег не мешает работать с рабочим столом и окнами.
- **Прячется в играх** — в полноэкранных программах (игры, видео, браузер по F11) и в программах из списка исключений снег исчезает и почти не тратит процессор.
- **Значок в трее** — двойной клик открывает настройки, правая кнопка — пауза, «стряхнуть сугробы», выход.
- **Окно настроек на Qt6** — количество, скорость, ветер и размер снежинок, плавность (FPS) с подсказкой о нагрузке, высота и скорость роста сугробов, исключения, автозапуск. Изменения применяются сразу, без перезапуска.
- **Автозапуск** — по галочке в настройках, сразу в трей.

## Требования

- Windows 10 или 11
- Python 3.10 или новее (64-bit) — [python.org](https://www.python.org/downloads/)
- PySide6 — только для окна настроек; сам снег работает на стандартной библиотеке

## Установка и запуск

```bash
git clone https://github.com/PhantomXVA/desktop-snow.git
cd desktop-snow
pip install -r requirements.txt
```

Запуск — двойной клик по `start.bat` или:

```bash
pythonw snow.pyw
```

При первом запуске откроется окно настроек, снег начнёт идти сразу. Закрытое окно настроек
сворачивается в трей — снег продолжает идти. Найти программу потом можно по снежинке в трее
(иногда она прячется под стрелкой `^` рядом с часами).

Запуск сразу в трей, без окна настроек:

```bash
pythonw snow.pyw --autostart
```

## Нагрузка на процессор

Снег не перерисовывается каждый кадр: слои снежинок нарисованы заранее, а в каждом кадре
окна со снегом только сдвигаются — это делает видеокарта через композитор Windows (DWM).
Сугробы перерисовываются кусочками и только когда растут.

Ориентировочная нагрузка (процесс снега + дополнительная работа DWM), замер на 16-поточном процессоре, 1920×1080:

| Плавность | % одного ядра | % всего процессора |
|-----------|---------------|--------------------|
| 15 FPS    | ~7%           | ~0.45%             |
| 30 FPS (по умолчанию) | ~15% | ~0.95%     |
| 60 FPS    | ~24%          | ~1.5%              |
| 120 FPS   | ~33%          | ~2.1%              |

Когда снег на паузе или спрятан (игра, полноэкранное видео, исключение) — нагрузка почти нулевая.

## Где хранятся настройки

- Настройки: `%APPDATA%\DesktopSnow\settings.json`
- Автозапуск: значение `DesktopSnow` в `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`
  (ставится и убирается галочкой в настройках)

## Как удалить

1. В настройках снимите галочку «Запускать вместе с Windows».
2. Выйдите через снежинку в трее → «Выход».
3. Удалите папку программы и, если хотите, `%APPDATA%\DesktopSnow`.

## Файлы

| Файл | Что это |
|------|---------|
| `snow.pyw` | Сам снег: слои снегопада, сугробы, трей, определение игр |
| `settings.pyw` | Окно настроек (PySide6) |
| `config.py` | Общие настройки и значения по умолчанию |
| `start.bat` | Запуск двойным кликом |

## Как это устроено

- **Снегопад** — три бесшовные текстуры 512×512 в прозрачных окнах (`UpdateLayeredWindow`
  с попиксельной альфой). Окна сдвигаются `SetWindowPos`; каждый слой разбит на две половины
  по ширине, потому что окно во весь экран Windows считает полноэкранной программой
  и включает режим «не беспокоить» для уведомлений.
- **Иконки** — координаты читаются из списка рабочего стола (`SysListView32` проводника),
  подписи сопоставляются с файлами рабочего стола, картинка иконки берётся из системного
  списка значков (`SHGetImageList`), и по альфа-каналу находится верхний контур.
- **Видимость** — сугроб на иконке показывается, только если иконку не закрывает окно
  (`WindowFromPoint`).
- **Игры** — снег прячется, если активное окно занимает весь монитор, если Windows
  сообщает об эксклюзивном полноэкранном Direct3D или режиме презентации,
  либо если активна программа из списка исключений.

## Известные ограничения

- Только Windows.
- Сугробы — на горизонтальной панели задач; на вертикальной (сбоку) снег не копится.
- У картинок с миниатюрами на рабочем столе форма неизвестна — сугроб ровный по центру.
- Конфигурация из нескольких мониторов и масштаб, отличный от 100%, почти не проверялись.
